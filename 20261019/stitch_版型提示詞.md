# Stitch 版型提示詞

請幫我生成一個以「旅遊」為主題的完整網站首頁，作為 CSS 切版練習的視覺參考。
頁面需包含導覽列（Navbar）、主視覺區（Hero Banner）、兩欄式內容區、三欄式卡片內容區，以及頁尾區（Footer）。

設計時請特別運用適合練習 CSS float、inline-block 橫向排列與 position 定位 的版面，
例如使用 float 實現圖文環繞或左右配置、使用 inline-block 將多張卡片橫向排列，
以及使用 position: relative 與 position: absolute 製作圖片上的文字或標籤定位。

整體風格清新、現代且具有旅遊氛圍，搭配適當的風景圖片、標題、文字與按鈕。請只生成完整的桌面版網頁視覺稿，
不需要 RWD，也不要提供 HTML、CSS 或 JavaScript 程式碼，讓我能依照設計稿自行練習 HTML 結構與 CSS 切版。
